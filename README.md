# Developer Portfolio & System Architecture Showcase

A modern, responsive portfolio application built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**, rewritten from the imported project and designed around the architectural specifications and idea files.

## 🌟 Key Features

- **Modern Visual Identity**:
  - Purple/violet brand identity (`#7130cf`) with glowing ambient orbs and subtle background grid.
  - Full dark / light mode with persistent preference detection and smooth transitions.
  - Interactive typewriter effect in the Selected Work section.
  - Multilingual support: instantaneous English and Bengali (বাং) navigation.

- **Project Showcase & Architecture Explorer**:
  - Categorized production systems (Laravel, React, POS, ERP, E-commerce, Reseller panels).
  - Status filters: *All*, *Active*, *In building*, *Planned*, and *Paused*.
  - Instant live keyword search with modal popup (`Cmd+K` / `Ctrl+K` or search button).
  - Detailed project view with system overview, key capabilities, tech stack badges, live demo and repository links.
  - High-resolution visual gallery with full-screen lightbox modal and zoom preview.

- **Admin Management Dashboard**:
  - Full CRUD capabilities for portfolio projects (Add, Edit, Delete, Reset to defaults).
  - Secure authentication with support for the original admin passcode (`2448766`) or Google login simulation.
  - Central inbox to view visitor inquiries and direct contact submissions.

- **Interactive Experience & Collaboration**:
  - Floating live chat widget with automated assistant, real-time message exchange, and quick chips.
  - Interactive notification panel with unread alert badges, project updates, and test push notification triggers.
  - Contact form with client-side validation, direct email/phone/WhatsApp reach-out links, and instant toast confirmations.
  - Privacy-first cookie consent manager with preferences drawer.

## 🛠 Tech Stack

- **Framework**: React 18 & TypeScript
- **Styling**: Tailwind CSS v4 & custom design tokens
- **Build Tool**: Vite
- **Icons**: Lucide React

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Build for production
npm run build
```
